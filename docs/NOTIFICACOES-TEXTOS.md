# Banco de notificações (rascunho para o dono aprovar)

Como funciona:
- A notificação mostra a **foto da modelo** no lugar do ícone (Android). No iPhone continua o ícone do app.
- `{nome}` vira o nome da modelo sorteada. A foto é a do perfil dela no app.
- Cada horário sorteia uma frase que o lead ainda não recebeu recentemente.
- **Tipo CHAT** abre o chat dela. **Tipo MÍDIA** abre o chat/vídeos dela. **Tipo ENCONTROS** abre a aba Encontros (só se Encontros estiver ligado; senão vira tipo CHAT).

Envios por dia: 4 (manhã 09:30, tarde 14:30, noite 20:30, tarde da noite 23:30).
Total: 64 frases = cerca de 16 dias sem repetir nada.
